Come si installa

Windows
  1. Apri UniNotes_setup.exe. Se compare «Windows ha protetto il PC», scegli Ulteriori informazioni → Esegui comunque: l'app non è ancora firmata.
  2. Segui l'installazione: non servono permessi di amministratore. UniNotes compare nel menu Start (e sul desktop, se lo scegli).
  3. Per aggiornare, installa il nuovo UniNotes_setup.exe sopra la versione precedente: i dati restano.
  4. Senza installazione: apri il file .zip, scegli Estrai tutto e avvia uninotes.exe.
  5. Microsoft Store (quando disponibile): cerca «UniNotes» nello Store e scegli Installa; gli aggiornamenti arrivano dallo Store. È la stessa app dell'installatore: basta una delle due.
  6. Se manca un file come MSVCP140.dll, installa il «Microsoft Visual C++ Redistributable x64» dal sito Microsoft.
macOS
  1. Apri UniNotes.dmg e trascina UniNotes sulla cartella Applicazioni.
  2. Al primo avvio macOS la blocca perché non è ancora firmata: apri Impostazioni di Sistema → Privacy e sicurezza e, in fondo, scegli Apri comunque.
  3. Per aggiornare, trascina in Applicazioni la UniNotes del nuovo .dmg: i dati restano.
Android
  1. Scarica il file .apk dal telefono e toccalo.
  2. Consenti l'installazione da questa fonte quando Android lo chiede, poi tocca Installa.
  3. Per aggiornare, installa il nuovo .apk sopra quello vecchio: i dati restano.
  4. Il pulsante scarica la versione per quasi tutti i telefoni (64 bit). Telefoni vecchi a 32 bit: versione 32 bit; Chromebook ed emulatori: versione x86_64.
iPhone e iPad
  1. Apple non permette di installare app non firmate. Finché UniNotes non è su TestFlight o sull'App Store serve uno strumento di sideloading (per esempio AltStore o Sideloadly) con il proprio Apple ID.
  2. Con un Apple ID gratuito l'app va reinstallata ogni 7 giorni.
